# Codex 执行任务｜双人动漫访谈视频本地生产线

阅读同目录 `Interview_Video_Local_Production_Plan.md` 全文，先执行 Gate 0 和 Gate 1，**不要立即生成30分钟**。

## 任务背景

设备：Mac mini M4 / 32GB，优先本地、原声、成本可控。双人角色：主持彦泽（棕色束发、白外套、单手持麦），嘉宾张岚（短黑发、黄衣熊猫图案、彩色围巾工牌、桌面麦克风）。人物有对视、嘴型、自然眼神与身体动作。已存在约58分钟真人采访，计划剪成约30分钟。后续60分钟系列采访可复用该生产线。

## 禁止行为

- 不用音量驱动的简单双帧张嘴冒充真实精准口型；纯演示须如实标注。
- 不自动替换受访者原声，不合成不存在的采访内容。
- 不擅自上传受访者材料，不调用收费 GPU/API。
- 不擅自更改角色设定、增加麦克风或改变服装。
- 不跳过小样验证直接批量渲染。
- 不在未验证时声称“已完成”“已测试通过”。

## 第一批具体任务

1. 发现实际视频/参考人物图路径（无文件则如实报告，保留工程结构）；检查音轨、格式和元信息；计算原始素材 SHA256。
2. 运行软件环境扫描（brew、node、ffmpeg、uv、Python、可用磁盘及统一内存），制作 `qa/preflight_report.md`。
3. 从**实际存在的原声文件**选择连续 10 秒：包含彦泽和张岚分别说话。制作两路对应的带静音角色音轨，不改变声音音色；重叠说话要标注。
4. 用 Whisper/逐字稿核对真实汉字，建立带时码的说话人标签。用 MFA Mandarin forced alignment 得到音素 TextGrid；将音素映射到至少10类口型，必要时绘制/切分缺失的嘴型素材。
5. 开发最小可行两人分层 Rig 动画，含 mouth/eye/head/gesture、听众闭嘴和互视。优先制作 10 秒真实口型 MP4 与音画 QA。
6. 选作同一原声样片的 Adobe Character Animator、Rhubarb phonetic 对照（软件若未装/需付费仅记录，不购买）。
7. 将有效组件写入可复用代码和 Skills；保留 `character_bible.md`, `visemes.json`, `review.csv`, `qa_report.md`。
8. 技术通过后扩展 60秒 → 5分钟，每一关产出审片素材/截图和报告；经确认再开发完整剪辑。

## 10秒验收数据

- 10秒 MP4 可本机播放；音轨来自源文件且两人身份正确。
- 口型分多形态，重点闭口辅音与开/圆/扁口元音有清楚变化。严禁简单音量开关循环。
- 抽取至少30个口型变化点比对音频，目标90%以上 ±100ms；其它失败点可在校对表定位。
- 听众静音时闭口，有自然眨眼和微动作；两人视线自然。
- 角色身份、衣服、工牌、话筒正确，中文字幕无乱码；所有错误可复现。
- 提交 `test_10s.mp4`, `qa_report.md`, 角色与口型数据、实际工具版本、内存峰值、实际运行时长。

## Gate 1 不通过时

优先修复文本和音素对齐、嘴型素材不足、Rig 坐标偏移和说话人错位。若两条本地方案都无法达到阈值，提供明确故障证据及另行授权的云 GPU 测试方案，禁止隐瞒失败。

## Gate 2 / Gate 3 / Gate 4

- Gate 2: 连续60秒；至少3个镜头，一次说话交接，一次B-roll，一套字幕；完整观看并留反馈。
- Gate 3: 5分钟完整章节；流畅性、身份连续性、切镜、字幕、声音、渲染负载与收益复盘。
- Gate 4: ~30分钟整片；完整播放、声画与授权 QA；交付 MP4/SRT/封面/工程/QA报告。
