# Codex 执行任务书｜双人动漫访谈视频本地生产线

先完整阅读同目录的 LOCAL_PRODUCTION_PLAN.md，再按 Gate 0 → Gate 1 执行。**不要直接生成30分钟成片。**

## 项目背景

- 设备：Mac mini M4 / 32GB 统一内存。
- 输入：约58分钟真人访谈、逐字稿、彦泽和张岚人物参考图。
- 输出：约30分钟、16:9、1920×1080、30fps、H.264/AAC 的双人动漫访谈。
- 声音：必须保留真实会议原声，不使用合成声音替代。
- 角色：彦泽（棕色束发/盘发、白色外套、手持且仅一支麦克风）；张岚（黑色短发、黄色熊猫图案上衣、彩色围巾/工牌、桌面麦克风）。
- 默认预算：本地运行，不调用收费视频 API，不开通云 GPU。

## 禁止行为

1. 不用按音量开合的简单双帧嘴型冒充精准口型。
2. 不自动替换受访者原声，不合成不存在的采访内容。
3. 不擅自上传原视频、人物图、声音或逐字稿。
4. 不擅自改变人物脸型、服装、发型、麦克风数量和场景方向。
5. 不跳过10秒、60秒、5分钟测试直接批量渲染。
6. 未经实际运行和验收，不得报告“已完成”或“已测试通过”。

## 第一批任务：10秒样片

1. 在本机发现原视频、逐字稿和人物参考图的真实路径；缺少素材时报告，不猜测路径。
2. 运行环境扫描：macOS、芯片、统一内存、磁盘空间、外置盘格式、Node、FFmpeg/FFprobe、Python、uv、Git。
3. 检查原始媒体信息并计算 SHA256，原始文件只读。
4. 提取48kHz WAV 原声母带及16kHz识别副本；不改变音色。
5. 使用 whisper.cpp 转写，结合逐字稿人工核对汉字、时间戳和说话人；重叠说话或第三人声音单独标注。
6. 选择一段真实连续的10秒双人对话，包含彦泽和张岚各自发言及交接；不得拼接出原话不存在的意思。
7. 使用 MFA 普通话模型做音素强制对齐，生成 TextGrid；把音素映射为多类 viseme，保留低置信度与人工修订字段。
8. 开发最小双人分层 Rig：mouth、eyes、brows、head、gesture 独立可控；说话者驱动口型，听众自然闭口并互视。
9. 用相同 WAV 对照 Adobe Character Animator 和 Rhubarb phonetic（如已安装或可免费运行）；不购买订阅。
10. 生成10秒 MP4、帧图、viseme 数据、对齐复核表、QA 报告、工具版本、内存峰值和实际运行时间。

## 10秒验收标准

- MP4 可本机播放，音轨来自原始会议文件。
- 说话人归属100%正确。
- 至少30个代表性口型/闭口点人工抽查，90%以上与声音偏差不超过±100ms。
- 有闭唇、圆口、扁口、张口等多种形态；禁止仅按音量开合。
- 连续300ms以上静音时自然闭口。
- 听众不抢嘴；双人视线自然；眨眼和轻微动作不机械重复。
- 角色身份、衣服、工牌、麦克风数量和位置正确。
- 中文字幕无乱码；音频没有突兀切断。
- 报告区分自动检测和人工确认，不得虚报通过。

## 后续 Gate

### Gate 2：60秒
至少3个镜头（双人、彦泽、张岚），一次自然发言交接、一次听众反应、一次有来源的插图、中文字幕。完整观看并留记录。

### Gate 3：5分钟
完成一个完整章节。检查内容连贯、人物一致性、口型、镜头节奏、音频、字幕、内存峰值、渲染耗时和返工成本。

### Gate 4：约30分钟
锁定内容和最终音轨后批量渲染。完整播放检查、核对原始内容时间戳、授权、字幕、媒体参数和最终交付包。
