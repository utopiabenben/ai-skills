# 本地动漫访谈视频生产方案

本目录沉淀「彦泽 × 张岚」双人动漫访谈的本地生产流程，后续可复用于《村长访谈》及其他行业人物访谈。

## 文件

- [本地制作技术方案](./LOCAL_PRODUCTION_PLAN.md)：从原始视频、声音、人物素材，到口型、动画、自动剪辑、导出和验收的完整流程。
- [Codex 执行任务书](./CODEX_IMPLEMENTATION_BRIEF.md)：可直接交给 Codex 执行的分阶段任务。
- [视频 QA 验收清单](./VIDEO_QA_CHECKLIST.csv)：各阶段的测试项目、验收方式和通过标准。

## 当前项目基线

- 设备：Mac mini M4 / 32GB 统一内存。
- 输入：约58分钟真人访谈视频、逐字稿、彦泽与张岚人物参考图。
- 目标：剪辑成约30分钟、16:9、1080p、30fps 的双人动漫访谈。
- 声音：保留真实采访原声，不用合成声音替代。
- 主路线：中文语音对齐 + 分层2D角色动画 + HyperFrames/FFmpeg本地合成。
- 预算：默认不调用付费视频 API 或云 GPU；任何云端处理须单独审批。

## 状态说明

本目录内容是技术设计、工具选型和验收规范。尚未代表整条生产线已在用户 Mac 上端到端验证。必须按 10秒、60秒、5分钟、30分钟逐级通过验收，不得跳级批量渲染。
